Calculator

Features
1. number pad
2. Standard operations(plus, minus, multiply, and divide)
3. square root the current number
4. percentile of current number
5. ac clears only current  number
6. c clears all information
7. point makes the next numbers decimals

how to use app
1. when app is loaded push any numbers in a row
2. push one of the operations on the right
3. input a new number
4. push equals
5. when you next click a number the previous output will be cleared

Additional features

when the root or percent button is pushed it affects the current number and gives that as output.
pushing the root or percent button will ignore the current operations.

pushing the point button will make the next numbers decimals.
numbers will go back to whole numbers when an operation is selected or equals sign is pressed.
